## Описание задачи

Проект посвящён задаче предиктивного обслуживания промышленного оборудования.

Необходимо построить модель бинарной классификации, которая по операционным параметрам оборудования предсказывает вероятность отказа машины. Такая задача актуальна для промышленности, так как раннее обнаружение возможного отказа позволяет снизить простой оборудования, уменьшить расходы на ремонт и повысить надёжность производственного процесса.

**Задача:** бинарная классификация.

**Датасет:** AI4I 2020 Predictive Maintenance Dataset.

**Источник:** Kaggle.

**Ссылка на датасет:**  
[https://www.kaggle.com/datasets/shivamb/machine-predictive-maintenance-classification](https://www.kaggle.com/datasets/shivamb/machine-predictive-maintenance-classification)

**Целевая переменная:** `Machine failure`.

**Положительный класс:** `1` — отказ оборудования.

**Отрицательный класс:** `0` — отказа оборудования нет.

**Целевая метрика:** PR-AUC.

**Дополнительные метрики:** F1-score, Recall, Precision, ROC-AUC, confusion matrix.

PR-AUC выбрана как основная метрика, потому что задача является несбалансированной: отказ оборудования встречается значительно реже, чем нормальная работа. Accuracy в такой ситуации может быть неинформативной, так как модель может получать высокое значение accuracy, почти всегда предсказывая отсутствие отказа.

## Данные

Используется датасет **AI4I 2020 Predictive Maintenance Dataset**.

Файл с исходными данными находится в:

```text
data/raw/ai4i2020.csv
```

Датасет содержит:

- **10 000 строк**;
- **14 колонок**;
- бинарную целевую переменную `Machine failure`.

Основные признаки:

| Признак | Описание |
|---|---|
| `Type` | Тип продукта |
| `Air temperature [K]` | Температура воздуха |
| `Process temperature [K]` | Температура процесса |
| `Rotational speed [rpm]` | Скорость вращения |
| `Torque [Nm]` | Крутящий момент |
| `Tool wear [min]` | Износ инструмента |

Целевая переменная:

| Переменная | Описание |
|---|---|
| `Machine failure` | Факт отказа оборудования |

В датасете также есть служебные признаки:

| Признак | Причина исключения |
|---|---|
| `UDI` | Технический идентификатор строки |
| `Product ID` | Уникальный идентификатор продукта |

Они не используются при обучении моделей, так как не описывают физическое состояние оборудования.

Также исключаются признаки типов отказов:

```text
TWF, HDF, PWF, OSF, RNF
```

Эти признаки являются индикаторами конкретных типов отказа. Их использование может привести к data leakage, так как они напрямую связаны с целевой переменной `Machine failure`.

## Обработка данных и feature engineering

В рамках CP1 выполнены следующие этапы обработки данных:

- проверен размер датасета;
- проверены пропуски;
- проверены полные дубликаты;
- изучены типы признаков;
- проанализировано распределение целевой переменной;
- изучен дисбаланс классов;
- исключены идентификаторы `UDI`, `Product ID`;
- исключены признаки утечки данных `TWF`, `HDF`, `PWF`, `OSF`, `RNF`;
- выполнен анализ числовых и категориальных признаков;
- построены визуализации распределений и зависимостей;
- выполнена проверка выбросов методом IQR;
- выполнено стратифицированное разбиение на train/validation/test в пропорции 70/15/15.

Распределение целевой переменной:

| Класс | Количество | Доля |
|---|---:|---:|
| `0` — отказа нет | 9661 | 96.61% |

Данные разделены следующим образом:

| Выборка | Класс 0 | Класс 1 |
|---|---:|---:|
| Train | 6763 | 237 |

Благодаря стратификации доля положительного класса во всех выборках сохраняется примерно на уровне 3.4%.

### Feature engineering

Были добавлены новые признаки:

| Новый признак | Описание |
|---|---|
| `temperature_diff` | Разница между температурой процесса и температурой воздуха |
| `power_proxy` | Приближённая нагрузка: произведение скорости вращения и крутящего момента |
| `torque_per_rpm` | Отношение крутящего момента к скорости вращения |
| `wear_torque_interaction` | Взаимодействие износа инструмента и крутящего момента |

Анализ важности признаков показал, что новые признаки оказались полезными для модели. Наиболее важными стали:

1. `temperature_diff`;
2. `power_proxy`;
3. `wear_torque_interaction`.

## Моделирование

В рамках CP1 были обучены и сравнены несколько моделей.

Baseline-модели:

- `LogisticRegression`;
- `LogisticRegression` с `class_weight='balanced'`.

Модели для экспериментов после feature engineering:

- `LogisticRegression`;
- `LogisticRegression` с `class_weight='balanced'`;
- `RandomForestClassifier`;
- `ExtraTreesClassifier`;
- `GradientBoostingClassifier`;
- `HistGradientBoostingClassifier`.

Для всех моделей использовался `sklearn Pipeline`.

Предобработка:

- числовые признаки масштабировались через `StandardScaler` для линейных моделей;
- категориальный признак `Type` кодировался через `OneHotEncoder`;
- для моделей на основе деревьев числовые признаки передавались без масштабирования.

## Результаты

### Baseline-модели на validation

| Эксперимент | Модель | Признаки | PR-AUC | ROC-AUC | F1 | Precision | Recall |
|---|---|---|---:|---:|---:|---:|---:|
| baseline | Logistic Regression | raw features | 0.3565 | 0.8427 | 0.2623 | 0.8000 | 0.1569 |
| baseline_balanced | Logistic Regression | raw features | 0.3083 | 0.8402 | 0.1918 | 0.1115 | 0.6863 |

Обычная логистическая регрессия показала более высокий PR-AUC и F1-score, но низкий Recall. Модель с `class_weight='balanced'` лучше находила отказы, но давала много ложных срабатываний.

### Эксперименты с feature engineering на validation

| Модель | PR-AUC | ROC-AUC | F1 | Precision | Recall |
|---|---:|---:|---:|---:|---:|
| Gradient Boosting FE | 0.8661 | 0.9532 | 0.8132 | 0.9250 | 0.7255 |
| Random Forest FE | 0.8422 | 0.9569 | 0.8298 | 0.9070 | 0.7647 |
| HistGradientBoosting FE | 0.8351 | 0.9451 | 0.8298 | 0.9070 | 0.7647 |
| Extra Trees FE | 0.7625 | 0.9371 | 0.6863 | 0.6863 | 0.6863 |
| Logistic Regression FE | 0.3900 | 0.8726 | 0.3143 | 0.5789 | 0.2157 |
| Logistic Regression Balanced FE | 0.3454 | 0.8860 | 0.2360 | 0.1402 | 0.7451 |

Лучшей моделью по основной метрике PR-AUC на validation-выборке стала:

```text
Gradient Boosting FE
```

### Финальная оценка лучшей модели на test

| Модель | Dataset | PR-AUC | ROC-AUC | F1 | Precision | Recall | TN | FP | FN | TP |
|---|---|---:|---:|---:|---:|---:|---:|---:|---:|---:|
| Gradient Boosting FE | test | 0.9301 | 0.9774 | 0.9375 | 1.0000 | 0.8824 | 1449 | 0 | 6 | 45 |

На test-выборке модель обнаружила **45 из 51** реального отказа и не допустила ложных срабатываний.
